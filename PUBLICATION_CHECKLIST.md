# MEW Privacy Policy — publication checklist

This archive contains a static bilingual policy web page (`index.html`) and matching English/Spanish Markdown sources.

**Contact email confirmed:** vibricsolutions@gmail.com. **Publication still requires final review and user approval.** Before uploading:

1. **Completed:** Public contact email confirmed in English, Spanish, and HTML files: `vibricsolutions@gmail.com`.
2. Confirm the displayed developer name exactly matches the Google Play listing (draft currently uses MovementOutside).
3. Confirm implementation against the final release: any granted permissions, third-party SDKs, ad formats, retention and deletion handling, and any new diagnostics or analytics must be reflected accurately.
4. Confirm the policy URL is reachable in a private browser tab, without login, payment or geoblocking. Google Play requires a publicly accessible non-PDF privacy policy.
5. Publish the page using a dedicated public GitHub Pages repository e.g. `mew-privacy-policy`, without exposing source code of the private `MEW` repo. GitHub Pages will host this as `https://movementoutside.github.io/mew-privacy-policy/` **only if** the repo and Pages are configured; this is a suggested URL, not a verified live URL.
6. Insert the real URL in AdMob -> Privacy & messaging -> European regulations -> MEW -> Add URL, and add it to Google Play Console app content and inside the Android app UI.
7. Align the Play Console Data safety questionnaire with the actual release and SDK documentation, then re-check for each major update.
8. Translate into additional languages only after review of the two master languages and user needs.

**Scope:** Privacy policy only. This is not a guarantee of legal compliance or a substitute for professional legal advice. Current features have NOT been remotely activated, so the page distinguishes optional future-enabled functions.

**Safety:** No cookies, tracking scripts, JavaScript, advertising pixels or external fonts are embedded in the static privacy page.
